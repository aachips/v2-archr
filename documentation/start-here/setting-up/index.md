Alright, so you want to start your own local home repair coalition? You wish to set up the frameworks and systems, before a natural disaster strikes your region.

What that means: This software has an [open repository you can find here]. You are free to download and run with this as long as you are helping people and not repurposing out of it's original intention or selling it for profit.

Even with the source code, you will need a few skillsets and resources to set up. 

+ First you will need private web hosting. If you are partnering with local groups, someone may have web hosting they are willing to share.
+ Second, you will need to be comfortable working in a code repository to get this set up and running. You will need to import a database script file and configure a workspace to work with on the back-end.
+ Third, you will need a team. Of individuals. Of groups. Organizations. Non-profits. Businesses. Local Government, even. Be ready to write grants and solicit funders. Have evidence and documentation of your work.

This isn't easy. It's not a simple download. It's blood, sweat, and tears. And it's lots of fun when you make it into a game that helps your neighbors.

And even with all of this, you may need to reach out to our development team for assistance. 

We are available for basic support requests and for anything more than that, contracting to help you establish your local home repair fronts. 

We can help modify the source code into a branch that is more particular to your local needs and infrastructure.

For now, there is more documentation and support pages on how you can get started, forming partnerships, soliciting financial support for home repairs, and delegating volunteer and staff crew teams.
