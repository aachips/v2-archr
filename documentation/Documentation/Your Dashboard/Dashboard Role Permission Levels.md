### Last updated 7/23/2026

There are roughly 13 unique roles that make up the dashboard. 
Instead of making 13 different dashboard versions and views for each role, we are simplifying this into FOUR permission levels. Ranging from 0-3. 
### Level 0: 

For a Volunteer or Requestor. This is the machine that compiles information. It can be easily overrun by a level 2/3. This is a boolean on account settings set between a recipient of home repair help and entry level helper. They look very different and have different information. For a requestor it is similar to the 'Case Review' but for one's own home repair application, to track their status. 

For a Volunteer. The first information that comes up is a welcome message with the person's name and a comment like 'Thank you for showing up for your neighbors.' In account settings you can mark your general availability, skills and experience, and some other helpful personal information.

Roles include: 
+ Volunteer
+ Requestor

### Level 1:
This permission level has basic ability to alter or make changes. They can look up cases, with a limited purview. They can access an abridged version of cases, and make changes. Those changes are always logged in the immutable progress ledger and reversible. There are protections against very destructive changes such as deleting an entire table or spreadsheet. Very case sensitive information is protected. We have office volunteers who come in and help with manual computer tasks. They have to apply for a volunteer role, which is done through the organization's website, not our platform. However, having a volunteer application, similar to the requestor one, which upon submission, generates a level 0 Volunteer account, is part of the functioning and entry points of this platform.

Roles include: 
+ Crew Member
+ Assessor
+ Subcontractor
+ Crew Lead (A couple of extra permissions and responsibilities)
### Level 2: 
This permission level is Office Administrative and gives much more ability to make changes in the database tables, supervise tasks and progress items, and view case-sensitive information about cases, clients, and donors. 

Roles include: 
+ Bursar
+ Envoy
+ Organizational Administrator
+ Project Manager

This is a fluid role, as each person can fulfill duties of any of those roles. So all of those roles are items in the side-menu which can alter how the dashboard looks, or give basic options within each of those roles. This role is organization-specific, so it will only render information relevant to your organization. And there will be administrators in different organizations that are part of the coalition.

### Level 3:

This is the Super-Administrator role, and is generally an I.T./Development/Sandboxing Role. One of the core crucial features we haven't built in is a bug report and support chat. If you run into problems with the platform, there is a Super-Administrator, available during working hours within 30 minutes to respond and take the helpdesk ticket. The Super-Administrator is also the role which implements the installation and configuration of the platform when it is offered open-source, so that accounts and organizations can be added. A super-administrator serves all of the organizations within the coalition. They are also tasked with writing documentation and standard operating procedures so that tasks and processes are not gatekept, but available in a document library to anyone in the coalition who wishes to read them.
