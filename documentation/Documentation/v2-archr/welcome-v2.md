Hello, if you are reading this help document, it means we are really close to a soft release of version 2 of the ARCHR Platform. 

At the moment, we are seeking out dedicated server hosting for our user account system. This might take a couple weeks. 

Once the platform goes up, we will need to get your help user testing, to ensure data integrity and security of this new system. It will be populated with dummy data. A user testing session will involve taking a unique and complex home repair situation, and recreating it together to see what works and doesn't work. 

Thank you for your patience. Unlike Disaster Response, of which by nature is urgent and immediate, software development is slow and intentional. Rushing that process creates more problems than it fixes, and we are building this looking at the years, and decade ahead. 

We are also creating a system which is open-source and shareable, so that other regions can set up a home repair coalition, before a natural disaster hits. 

As of the end of September 2026, this Help Library is the only element of the new system up. The goal of the Help Library is to have a space for support documentation, and standard operating procedures. 

We need help building this library, and part of our check in survey being sent out will ask if you can commit to writing at least one support document to add to our library. These can be publicly viewable, or have an internal visibility for only ARCHR staff.
