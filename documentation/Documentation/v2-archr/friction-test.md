Here is a list of tasks. A scavenger hunt if you will, to perform together at our next weekly meeting for the Softr interface. This is a friction test of intentional tasks that will reveal helpful information. This is also a helpful 'before' test to show how far we will have come.

Here is a list of partner-level Softr interface tasks, organized by category, that exposes the system's current state:

### Finding Client Information

+ Find a specific client by name (use a test or dummy record)
+ Find a client by PlaceCode
+ Pull the complete history of one client (interactions, repairs, documents)
+ Find all clients in a specific zip code or neighborhood

### Updating and documenting

+ Add a note to a client's record about a phone call or site visit
+ Upload a photo (before, during, after) to a client's record
+ Find that photo in a fresh browser session
+ Mark a repair as 'in progress' and assign it to a contractor
+ Generate a document (work order, approval letter, intake summary)

### Tracking and Reporting

+ Find all clients whose applications are pending approval
+ Find all repairs completed in last 30 days
+ Find all clients referred by a specific partner organization
+ Export a list of clients (with basic info) to CSV or PDF

### Navigation and Orientation

+ Find page that explains what this system is for (help, about, guide)
+ Log out and log back in
+ Find a way to contact support or report a problem

## Assessing each task

+ Steps: How many clicks, page loads, or actions from start to finish
+ Time: Rough seconds or minutes (use a stopwatch on a few)
+ Dead ends; Did you get stuck? Did you have to guess? Did you give up?
+ Workarounds: Did you have to do something the system didn't intend? (like using a note field to store a photo link?)
+ Emotional Response: Frustrated? Confused? Relieved? Fine? (just a word or two)

### What to look out for

+ Hidden fields - Important information tucked away, requires extra clicks
+ Inconsistent naming
+ Missing Search - can't find a record you know exists
+ Broken Exports - CSV missing columns, or data is unreadable
+ Photos that don't appear
+ Status ambiguity - What does "in progress" mean
+ No audit trail - can't tell who changed what, or when
+ Too many tools - in order to complete one task, have to leave platform to go to another system
