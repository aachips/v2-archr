### Claiming and Completing a Task

As a: Volunteer with basic skills
I want to: Claim a debris cleanup task
So that: I can contribute after work hours

Acceptance Criteria:
1. Dashboard shows available quests within 10 miles
2. Quest card shows: time estimate, XP reward, required tools
3. One-click claim (no approval needed for Level 1 tasks)
4. Task added to "Active Quests" section
5. After completion, volunteer uploads before/after photos
6. Crew Lead verifies within 48 hours
7. XP and reputation auto-awarded on verification

### As a experienced volunteer

I want to: See my reputation grow
So that: I can access higher-value quests

Acceptance Criteria:
1. Profile shows reputation meter (0-1000)
2. Each completed quest adds 5-20 reputation points
3. Positive beneficiary feedback adds bonus points
4. Reputation tier badges appear on profile
5. Level 3+ volunteers see "priority" quests first
6. Level 5 volunteers get special recognition in newsletter

### Community Content

As a: Volunteer who enjoys writing
I want to: Share my field notes and photos
So that: Others learn from my experiences

Acceptance Criteria:
1. "Share Story" button on completed quests
2. Markdown editor with photo embedding
3. Submit for review (admin approves within 3 days)
4. Published stories appear in "Volunteer Voices"
5. Author receives 50 XP per published story
6. Most-liked stories get pinned to newsletter
7. Path to "Volunteer Contributor" role after 5 stories
