# CASEWORKER ROLE DEFINITION (DRAFT)

## Who Are They?

| Attribute | Description |
|-----------|-------------|
| **Job Title** | Case Manager / Intake Specialist / Client Coordinator |
| **Department** | Client Services / Programs |
| **Technical Comfort** | Medium |
| **Work Location** | Office (with phone/email) |
| **Client Interaction** | Primary - direct client support |

## What They Need To Do

| Priority | Task | Frequency |
|----------|------|-----------|
| **P0** | Review applications | Daily |
| **P0** | Communicate with clients | Daily |
| **P0** | Coordinate services | Ongoing |
| **P1** | Manage case files | Weekly |
| **P1** | Document all interactions | Ongoing |
| **P2** | Coordinate with assessors | As needed |
| **P2** | Coordinate with subcontractors | As needed |

## What They Need To See (Dashboard)

| Element | What It Shows |
|---------|---------------|
| **Assigned Cases** | Their active cases |
| **Pending Actions** | What needs their attention |
| **Messages** | Client communications |
| **Calendar** | Appointments and deadlines |

## What They Need To Create/Update

| Action | Description |
|--------|-------------|
| **Review Applications** | Initial screening |
| **Update Case Status** | Track progress |
| **Log Communications** | Record all interactions |
| **Request Documents** | Ask clients for verification |
| **Schedule Appointments** | Coordinate with clients |
| **Add Notes** | Case documentation |

## Who They Interact With

| Person | Interaction |
|--------|-------------|
| **Requestor** | Primary contact |
| **Assessor** | Assessment coordination |
| **Project Manager** | Repair coordination |
| **Administrator** | Assignment and support |

## What Would Frustrate Them

| Frustration | Why It Matters |
|-------------|----------------|
| Duplicate communications | Wastes time, confuses clients |
| Can't see client history | Repeats questions |
| Poor phone workflow | Can't document calls |
| Manual data entry | Takes time from clients |

## What's The Impact?

| If They Do Well | If They Don't |
|-----------------|---------------|
| Clients feel supported | Clients feel abandoned |
| Cases move forward | Cases stall |
| Trust in ARCHR grows | Trust erodes |

## Initial Assumptions to Validate

- [ ] They are primary client contact
- [ ] They spend most time on phone/email
- [ ] They need to document EVERY interaction
- [ ] They need clear visibility into case status
- [ ] They need to coordinate with other staff
- [ ] They need to know what's urgent
- [ ] They need to track action items
- [ ] They need to handoff between staff
