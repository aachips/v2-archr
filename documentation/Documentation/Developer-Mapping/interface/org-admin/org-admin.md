# ORGANIZATION ADMINISTRATOR ROLE DEFINITION

## Who Are They?

| Attribute | Description |
|-----------|-------------|
| **Job Title** | Program Director / Operations Manager / Executive Director |
| **Department** | Organization Management |
| **Technical Comfort** | Medium |
| **Work Location** | Office (may also work hybrid) |
| **Client Interaction** | Minimal - primarily staff management |

## What They Need To Do

| Priority | Task | Frequency |
|----------|------|-----------|
| **P0** | Oversee applications assigned to their org | Daily |
| **P0** | Assign cases to staff | Ongoing |
| **P0** | Review eligibility determinations | Ongoing |
| **P1** | Manage caseworker workload | Weekly |
| **P1** | Coordinate with other orgs | Weekly |
| **P2** | Reporting and oversight | Monthly |
| **P2** | Staff management | Ongoing |

## What They Need To See (Dashboard)

| Element | What It Shows |
|---------|---------------|
| **Recent Applications** | Latest with nextStep + holdingOn |
| **Task Counts** | Processing, verification, comms, scheduling |
| **Previous Applications** | History with status |
| **Latest Events** | Recent timeline updates |
| **Latest Messages** | Unread communications |

## What They Need To Create/Update

| Action | Description |
|--------|-------------|
| **Review Applications** | Confirm/deny eligibility |
| **Assign Staff** | Caseworker allocation |
| **Set Triage** | Priority determination |
| **Update Info** | Correct applicant data |
| **Take Notes** | Internal staff notes |
| **Schedule Events** | Coalition/org events |
| **Manage Volunteers** | Schedule, communicate |
| **Manage Subcontractors** | Review, approve, coordinate |

## Who They Interact With

| Person | Interaction |
|--------|-------------|
| **Caseworkers** | Assignment and workload |
| **Other Orgs** | Coalition coordination |
| **Bursar** | Financial oversight |
| **Requestors** | Escalated issues |
| **Volunteers** | Coordination |

## What Would Frustrate Them

| Frustration | Why It Matters |
|-------------|----------------|
| Can't see workload | Can't balance team |
| No visibility into cases | Can't track progress |
| Duplicate outreach | Wasted staff time |
| No reporting | Can't show results |
| Manual assignments | Time wasted |
| Poor communication | Misalignment with staff |

## What's The Impact?

| If They Do Well | If They Don't |
|-----------------|---------------|
| Cases processed efficiently | Bottlenecks everywhere |
| Staff feel supported | Staff burn out |
| Coalition works together | Orgs compete |
| Partners trust ARCHR | Partners leave |

## Initial Assumptions to Validate

- [ ] They manage multiple staff
- [ ] They need visibility into all cases
- [ ] They need workload balancing
- [ ] They need to coordinate with other orgs
- [ ] They need reporting for funders
- [ ] They need to know which cases are stuck
- [ ] They need to know staff capacity
- [ ] They need to see communication history
