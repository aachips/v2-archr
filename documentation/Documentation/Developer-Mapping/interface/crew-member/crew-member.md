# CREW MEMBER ROLE DEFINITION

## Who Are They?

| Attribute | Description |
|-----------|-------------|
| **Job Title** | Construction Worker / Repair Technician / Crew Member |
| **Department** | Operations / Field Services |
| **Technical Comfort** | Low (uses phone for photos, maybe not much else) |
| **Work Location** | Field (job sites) |
| **Client Interaction** | Direct - works in client homes |
| **Reports To** | Crew Lead |

## What They Need To Do

| Priority | Task | Frequency |
|----------|------|-----------|
| **P0** | Perform assigned repair tasks | Daily |
| **P0** | Attend safety talk | Daily (required) |
| **P0** | Log hours | Daily |
| **P1** | Take photos of work | Per task |
| **P1** | Report issues to Crew Lead | As needed |
| **P2** | Sign incident reports if involved | As needed |

## What They Need To See (Dashboard)

| Element | What It Shows |
|---------|---------------|
| **Today's Assignment** | Where to go, what to do |
| **Task List** | What needs to be done today |
| **Safety Talk Confirmation** | Check box they received it |
| **Hours Logged** | Their time tracking |
| **Messages** | Communications from Crew Lead |

## What They Need To Create/Update

| Action | Description |
|--------|-------------|
| **Log Hours** | Clock in/out, daily hours |
| **Mark Safety Talk** | Confirm they received safety briefing |
| **Take Photos** | Progress and completion photos |
| **Task Status** | Mark tasks complete |
| **Report Issues** | Flag problems to Crew Lead |

## Who They Interact With

| Person | Interaction |
|--------|-------------|
| **Crew Lead** | Supervision, task assignment |
| **Other Crew Members** | Work together |
| **Volunteers** | Work alongside |
| **Homeowner/Client** | On-site work |

## What Would Frustrate Them

| Frustration | Why It Matters |
|-------------|----------------|
| Complicated app | Won't use it |
| Can't log hours on phone | Will forget or get it wrong |
| No safety talk reminder | Safety risk |
| Too many steps to update task | Won't update, PM loses visibility |
| Can't upload photos | Can't prove work done |

## What's The Impact?

| If They Do Well | If They Don't |
|-----------------|---------------|
| Work gets done correctly | Poor quality, rework |
| Hours tracked accurately | Payroll issues |
| Photos document quality | No proof of completion |
| Safety talk attended | Safety incidents |

---

## Key Distinctions from Crew Lead

| Aspect | Crew Lead (Required) | Crew Member (Optional) |
|--------|---------------------|----------------------|
| Safety Talk | **Deliver** the talk | **Receive** and confirm |
| Project Notes | **Required daily** | Not required |
| Incident Report | **File** report | Sign if involved |
| Volunteer Sign-off | **Verify** hours | Log own hours |
| Supervision | **Manage** others | Self-manage |

---

## Initial Assumptions to Validate

- [ ] Crew Members may not be tech-savvy
- [ ] Phone app should be very simple
- [ ] Safety talk confirmation should be one tap
- [ ] Hours logging should be quick
- [ ] Photos should be easy to take and upload
- [ ] Tasks should be clearly visible
- [ ] They should see only what affects them
