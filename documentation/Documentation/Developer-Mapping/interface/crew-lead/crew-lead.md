# CREW LEAD ROLE DEFINITION

## Who Are They?

| Attribute | Description |
|-----------|-------------|
| **Job Title** | Crew Lead / Site Supervisor / Construction Lead |
| **Department** | Operations / Field Services |
| **Technical Comfort** | Medium (comfortable with tools, okay with tech) |
| **Work Location** | Field (job sites) |
| **Client Interaction** | Direct - works in client homes, manages client relationship |
| **Reports To** | Project Manager |

## What They Need To Do

| Priority | Task | Frequency |
|----------|------|-----------|
| **P0** | Supervise on-site repair work | Daily |
| **P0** | Ensure safety talk delivered to crew/volunteers | Daily |
| **P0** | Sign off on completion documents | Per project |
| **P1** | Take project notes | Daily |
| **P1** | Report progress to Project Manager | Daily/Weekly |
| **P1** | Manage crew members and volunteers | Daily |
| **P2** | Verify work quality | Ongoing |
| **P2** | Coordinate materials and tools | As needed |
| **P3** | File incident reports when needed | As needed |

## What They Need To See (Dashboard)

| Element | What It Shows |
|---------|---------------|
| **Active Projects** | Their current job sites |
| **Today's Schedule** | Which site, who's assigned |
| **Crew Roster** | Who's working today |
| **Volunteer Sign-in** | Hours logged, safety talk checked |
| **Project Notes** | Daily updates and observations |
| **Completion Status** | Which projects are ready for sign-off |
| **Messages** | Communications from PM, admin, etc. |

## What They Need To Create/Update

| Action | Description |
|--------|-------------|
| **Project Notes** | Daily progress, issues, observations |
| **Safety Talk Record** | Check box for each volunteer/crew member daily |
| **Volunteer Hours** | Approve/verify hours logged |
| **Incident Report** | File when accidents or issues occur |
| **Completion Document** | Get client signature, upload to system |
| **Progress Photos** | During and after photos |
| **Task Updates** | Mark subtasks complete |
| **Material Requests** | Request supplies/tools |

## Who They Interact With

| Person | Interaction |
|--------|-------------|
| **Crew Members** | Direct supervision, task assignment |
| **Volunteers** | Safety briefing, task supervision |
| **Project Manager** | Progress reporting, escalation |
| **Homeowner/Client** | On-site coordination, satisfaction |
| **Subcontractors** | Coordinate schedule and scope |

## What Would Frustrate Them

| Frustration | Why It Matters |
|-------------|----------------|
| Too much data entry | Takes time away from supervising work |
| Can't log hours for volunteers | Volunteers don't get credit |
| Safety talk not tracked | Compliance and liability risk |
| Can't upload photos from phone | Essential documentation |
| Unclear completion process | Client doesn't get their certificate |
| Can't report issues quickly | Delays in getting help |

## What's The Impact?

| If They Do Well | If They Don't |
|-----------------|---------------|
| Repairs completed correctly | Rework, client dissatisfaction |
| Crew stays safe | Injuries, liability |
| Volunteers have good experience | Volunteers don't return |
| Clients sign off happily | Disputes, complaints |
| Project stays on schedule | Delays, budget overruns |

---

## Key Distinctions from Crew Member

| Aspect | Crew Lead (Required) | Crew Member (Optional) |
|--------|---------------------|----------------------|
| Safety Talk | **Deliver** the talk | **Receive** the talk |
| Completion Doc | **Get client signature** | May witness |
| Project Notes | **Required daily** | Can contribute |
| Incident Report | **File** report | May be subject of report |
| Volunteer Sign-off | **Verify** hours | Log own hours |
| Supervision | **Manage** others | Self-manage |

## Initial Assumptions to Validate

- [ ] Crew Lead is on site most of the day
- [ ] Safety talk is REQUIRED daily before work starts
- [ ] Completion certificate is a legal document
- [ ] Incident reports need to be filed quickly
- [ ] Photos are proof of work quality
- [ ] Volunteer hours need verification
- [ ] Project notes should be searchable by case
- [ ] Crew Lead needs ability to request materials
