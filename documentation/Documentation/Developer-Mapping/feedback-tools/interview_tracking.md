This directory contains ARCHR User Discovery Interview notes, with code for the sign-up form. Most of what is here of interest will be within /interviews/. This is a very basic way of documenting and tracking interviews with platform users. And it's immediately shareable. 

To the best of my abilities, names have been obfuscated with their initials. At the time of writing, this is completely private between me, the front-end developer, A., and the back-end developer, B.

The best way to use and interact with this is to configure local computer access to this repo on Visual Studio Code, and add notes and comments to each interview document through Markdown writing. Or just write and append content on Github directly.

These interviews are very dense and loaded, and I don't recommend conducting more than 1-2 of them in a week. The feedback branches into technical guidance and blueprints for moving forward, and processing that feedback from an interview requires time, attention, and collaboration.
    
At a later time, these will be linked on an AirTable, mostly to document for non-developers the work that has taken place. We will develop the document tracking for interviews as this initiative builds and develops.
