We are building four interconnected systems that work together in the background:+

Activity Log / Immutable Ledger
• Records everything that happens                                 
• Cannot be changed or deleted                                   
• Foundation for everything else  

Event Resolver
• Listens to the Activity Log                                     
• Decides what each event means            
• Triggers actions based on events                           
• Creates new events as reactions 

Task Engine
• Manages tasks that need to be done                              
• Assigns tasks to people                                
• Tracks task completion                                        
• Bumps incomplete tasks to the top  

State Mutator
• Changes the state of the Application/Case/Project           
• Unlocks new UI elements as milestones are reached          
• Controls what users can see and do
