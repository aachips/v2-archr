## Task Status Options

Each task can have one of the following statuses:

|Status|Meaning|Color|
|---|---|---|
|**Not Started**|Task hasn't begun|⚪ Gray|
|**In Progress**|Currently being worked|🔵 Blue|
|**Blocked**|Waiting on something|🟠 Amber|
|**Complete**|Task finished|🟢 Green|
|**Waived**|Not applicable to this case|⚪ Light Gray|
