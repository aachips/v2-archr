## Phase Gate Decision Points

At each phase boundary, the case must pass a review before proceeding:

|Phase Boundary|Gate Decision|Who Decides|
|---|---|---|
|Pre-Screen → Intake|Application passes all criteria|Caseworker|
|Intake → Processing|Case record complete, assessor assigned|Project Manager|
|Processing → Planning|Assessment done, budget set|Project Manager|
|Planning → Project|Contract signed, resources ready|Project Manager / Envoy|
|Project → Completion|All work signed off|Crew Lead / Homeowner|
|Completion → Closed|All costs reconciled|Bursar|
