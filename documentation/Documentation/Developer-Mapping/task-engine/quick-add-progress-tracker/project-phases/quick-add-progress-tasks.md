The Quick Add Progress Tracker is a unified interface for logging task completions across all six project phases. It adapts to the type of task being logged, shows only relevant fields, and automatically triggers document generation, updates the immutable ledger, and syncs with the case folder.

Once a job has been claimed, this process takes over. For the phases of Processing, Planning, and Project Repair. By claiming a case, the organization is agreeing and committing to doing all of the work. Please do not claim a case unless your organization is prepared to follow through to completion. When you click the 'Claim' button, there will be a pop-up notification explaining this and asking if you wish to proceed or not.

Throughout the multiple phases of the repair project, there are automated methods to enter in dates of completion for reporting and feeding metrics.

### What is a Task? How does our Task Engine work?

Something that needs to get done. Some are automatically generated while some are manually entered. If it needs to get done and you are not completing it right then and there, please [Log It](log-it.md).

Tasks can be quickly entered from your Dashboard home page. It can be a single line, many lines for multiple tasks, or many submissions. All of these will be peer-reviewed by a [Task Rabbit](task-rabbit.md).

Additionally there is a [Quick Add Progress Task](quick-add-progress-task.md) form you can click on. It will open a pop-up. From there you can select a formalized task from a drop-down menu and input additional information. These are based off the Phased lists above on items that need to get done to progress projects, from claim to completion. These can be anything from Repair related tasks like digging a hole, or Administrative Tasks like Income Verification.
