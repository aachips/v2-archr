## Phase 0: Submission & Pre-Screening

**Purpose:** Verify the application meets basic criteria before moving to formal intake.

| #   | Task                        | Description                                                                                             | Responsible |
| --- | --------------------------- | ------------------------------------------------------------------------------------------------------- | ----------- |
| 0.1 | Submit Application          | Applicant completes intake form                                                                         | Requestor   |
| 0.2 | Verify Storm-Related Damage | Confirm damage is from Helene/superstorm                                                                | Caseworker  |
| 0.3 | Geographic Eligibility      | Check if property is in service area                                                                    | Checker     |
| 0.4 | Income Eligibility          | Verify income meets program guidelines                                                                  | Checker     |
| 0.5 | Demographics Check          | Verify household demographics                                                                           | Checker     |
| 0.6 | GIS Check                   | Property mapping                                                                                        | Admin       |
| 0.7 | Collect Homeowner Documents | Can wait till assessment or upload earlier. Verify deed.                                                | Assessor    |
| 0.8 | Collect Income Documents    | Can wait till assessment or upload earlier. Verify acceptable income documents. Varies by Organization. | Assessor    |
| 0.9 | Decision Point              | Application passes → Phase 1                                                                            | Caseworker  |
| 1.0 | Decision Point              | Application paused, withdrawn, or ineligible → Exit                                                     | Caseworker  |

**Exit Conditions:**

- **Paused:** Missing information, awaiting applicant response
    
- **Withdrawn:** Applicant cancels or no longer needs assistance
    
- **Ineligible:** Does not meet program criteria
