## Phase 1: Intake

**Purpose:** Establish the case record and assign initial resources.

| #   | Task                        | Description                                  | Responsible     |
| --- | --------------------------- | -------------------------------------------- | --------------- |
| 1.1 | Create Project Record       | Generate case in ANCHOR                      | Software        |
| 1.2 | Initial Contact             | First outreach to applicant                  | Caseworker      |
| 1.3 | Claim Assessment            | Determine if organization can serve          | Project Manager |
| 1.4 | Assign Assessor             | Assign person to conduct home visit          | Project Manager |
| 1.5 | Schedule Assessment         | Set date/time for property inspection        | Caseworker      |
| 1.6 | Collect Income Documents    | Request proof of income if not submitted.    | Assessor        |
| 1.7 | Collect Ownership Documents | Request deed or tax record if not submitted. | Assessor        |
| 1.8 | Phase Complete              | All intake tasks done, move to Phase 2       | Caseworker      |
