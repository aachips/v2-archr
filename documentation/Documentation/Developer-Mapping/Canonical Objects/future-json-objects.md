1) Place Code Object - What makes up a Place Code? Differences with Project Code. Mapping Case vs Project vs Place. List of rules determining differences between the three.
2) Organization Object - Organization + Directory Records. When a project is claimed, what fields are impacted? When you set eligibility rules and projects are determined eligible, what fields go into that?
3)  Person Object - People and Individuals. The names and fields behind different roles. What organization are they a part of? What is their role? Or even for clients/requestors information that is helpful to keep track of. 
4) Project Event Objects - Dates, Milestones, Achievements. Progress Checker Stuff. Things that go on the Immutable Ledger.
5) Task Library Object - I think we did this for at least one type of task. I can't remember where it lives. 
6) Contract Object - with one contract per project, proposed contract vs signed vs completed.
7) Document Object - DocumentID, bucketRecordID, photoRecordID, proofOfPaymentDocumentID, etc. case_documents and project documents base bucket/docBuilder tables.
8) Intake Submission Object - Fillout submission. Similar to Anchor. Might be functionally the same. But pre-interpretation(?)
9) Funding Source Object - Donors, Balances, Receipts, Invoices, Timesheets, Quarterly Reports, Etc.
