## Asheville Habitat For Humanity

### Service Area(s):
+ Buncombe County
+ Madison County
+ North Carolina State
+ NC State
### Income Requirements:
Less than 80% <abbr title="Average Median Income">AMI</abbr>
### $ Proof Of Income Accepted:

+  Pay stubs
+  Social Security Benefit Letter
+  Disability Income
+  W2
+  Pension Statements
+  Alimony
+  Unemployment Benefits
+  Worker's Compensation
+  Veteran's Benefits
+  Net rental income
+  TANF Work First (agency letter)
+ Minor Children receiving benefits
+  Notarized Statement of Income
+  Net Gambling or Lottery Winnings
+  Dividends, Interest Bonds or Other Investment
### Proof of Ownership/Residency Accepted:

+ Property Tax Bill
+ Deed
+ Verification of Life Estate
+ Title
+ 99 Year Lease
+ Mobile Home Bill of Sale ( for mobile home repair )

Asheville Habitat for Humanity offers three different types of home repair: Disaster Repair, Home Repair, and Mobile Home Repair. Each has variation in Home Ownership Criteria.

### Home/Home Ownership Criteria
+ Type of Home: Stick-Built, Modular, Mobile, Other
+ $ Max Tax Value of Home: $450k
+ Primary Residence
+ Must Own Home
+ For non-disaster Home and Mobile Repair, there is a minimum length of residence as one year.
+ For mobile homes, you must own the lot
